What the status means

  1. Inventoried: a file family or structure has been counted; identity may still be inferred.
  2. Decoded: a parser reads relevant structures. This is not a claim that every field is understood.
  3. Converted: an output exists in a usable exchange format.
  4. Import verified: a target application has actually loaded the output.
  5. Runtime verified: behavior has been checked in its intended runtime.

Counts are evidence snapshots, not a percentage of the whole game. A category can contain mixed stages. Unknown names and purposes remain explicitly unresolved.
